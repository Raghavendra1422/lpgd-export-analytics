Farmer sourcing regions

This is about where the produce was bought from, not where it was sold. Nizamabad, Armoor, Jagtial etc. are the local sourcing areas. Use it to see which sourcing regions are giving the best return — but read the bar (total profit) together with the line (profit per shipment), since a region can look "best" simply because more shipments came from there. A region that's smaller but has a higher profit-per-shipment line is arguably the better one to lean on.
